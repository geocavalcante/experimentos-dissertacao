# Experimentos da Dissertação

Este repositório contém os códigos, dados e resultados utilizados na dissertação de mestrado intitulada "Título da sua dissertação".

## Estrutura do Repositório

- `scripts/` — Códigos-fonte utilizados nos experimentos
- `dados/` — Dados de entrada
- `resultados/` — Saídas, gráficos e logs
- `figures/` — Imagens utilizadas na dissertação
- `relatorio/` — Arquivos da dissertação
